# Termos de uso — AppCtrlFin

1. **Uso gratuito.** O AppCtrlFin pode ser baixado, instalado e usado gratuitamente, para fins pessoais.
2. **Seus dados são seus.** Tudo o que você registra fica apenas no seu computador. O app não envia dados financeiros para nenhum servidor. A única conexão que ele faz é para verificar se há versão nova.
3. **Estimativas.** As projeções, a visão global e as metas são estimativas calculadas a partir do que você informa. Não são recomendação financeira, de investimento ou contábil.
4. **Sem garantia.** O software é fornecido "como está", sem garantias. Faça backup do arquivo de dados regularmente (veja o manual).
5. **Redistribuição.** Indique este repositório como origem oficial dos instaladores. Não redistribua versões modificadas.
6. **Código-fonte.** O código-fonte não é público.
