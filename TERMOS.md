# Termos de uso — Time2Fin (antes AppCtrlFin)

1. **Uso gratuito.** O Time2Fin pode ser baixado, instalado e usado gratuitamente, para fins pessoais.
2. **Seus dados são seus.** Tudo o que você registra fica apenas no seu computador. O app não envia dados financeiros para nenhum servidor. As únicas conexões que ele faz são para verificar se há versão nova (na versão do instalador) e, se você usar, a sincronização com o celular pela sua rede Wi-Fi local. Veja a [política de privacidade](https://marcuslimaarruda.github.io/AppCtrlFin/privacidade.html).
3. **Estimativas.** As projeções, a visão global e as metas são estimativas calculadas a partir do que você informa. Não são recomendação financeira, de investimento ou contábil.
4. **Sem garantia.** O software é fornecido "como está", sem garantias. Faça backup do arquivo de dados regularmente (veja o manual).
5. **Redistribuição.** Indique este repositório como origem oficial dos instaladores. Não redistribua versões modificadas.
6. **Código-fonte.** O código-fonte não é público.
